# Pomfret Dashboard Kit: start here (for the person running the session)

Staff get this whole folder and talk to Claude in it. `CLAUDE.md` tells Claude how to set up their computer, build in the Pomfret style, and publish, so there's nothing for staff to paste.

**Before the session:** the person needs edit access to their Google Sheet, and you may need admin rights if their Mac asks to install developer tools.

**In the room (about 15 minutes the first time):**

1. Put this folder on their computer (later: download from GitHub).
2. Open the **Claude desktop app → Code tab → choose this folder**.
3. They type: **"Set me up."** Help them click through the Google sign-in (their @pomfret.org account) and turn on the Apps Script switch Claude links to.
4. They type: **"Make me a dashboard from** *[paste Sheet link]***."** Then describe what they want to see.
5. Open the preview link Claude gives, click **Review permissions → Allow** once, and look.
6. Ask for changes in plain words. When happy: **"Ship it."** Claude asks once who should be able to open it, then gives the live link.

**From then on:** open the folder in the Code tab and say what you want: *"change…"*, *"ship it"*, *"undo that"*, *"show me my dashboards"*, *"get the latest look"*.
